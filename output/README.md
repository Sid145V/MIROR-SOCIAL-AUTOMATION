# Generated Creative Output Directory

This directory stores all rendered Instagram creative outputs produced by the system.

## Directory Sub-Structure
- **`previews/`**: Development and test renders generated during template design or draft stages.
- **`approved/`**: Final QA-approved renders ready for Instagram publishing.
- **`failed/`**: Renders that failed validation checks, QA criteria, or asset integrity checks.

> **Note:** No creative output has been generated during Phase 1.
