# Approved Brand Logos

This folder contains approved production assets for MIROR logos.

## Asset Rules
- Never generate or recreate the MIROR logo.
- Never modify the original MIROR logo.
- Never invent missing brand assets.
- Only approved production assets should be placed here and used in production.
- The original asset must always be preserved.
- Asset IDs correspond to the Google Sheet `Asset_Library` (e.g., `LOGO-001`).
