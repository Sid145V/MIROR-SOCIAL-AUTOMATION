# Brand Asset Guidelines & Management

This document describes how production assets (logos, fonts, product shots, app screens, graphics, photography, and template planning references) are ingested, mapped to Asset IDs, and preserved for production rendering.

## Asset Principles
- Never generate or recreate the MIROR logo.
- Never modify the original MIROR logo binary.
- Never invent missing brand assets.
- Only approved production assets must be used.
- Asset IDs correspond to the production asset registry and Google Sheet `Asset_Library`.
