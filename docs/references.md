# Reference Material & Analysis Guidelines

This document will describe how reference screenshots placed in `references/instagram/` and `references/website/` are analyzed for template development.

## Key Guidelines
- Website references and Instagram references must remain separate.
- Website typography measurements must NOT automatically be treated as Instagram measurements.
- Reference files in `references/` are read-only approved samples and must not be modified.

> **Status:** Phase 1 Placeholder. Reference analysis workflows will be documented when reference images are analyzed.
