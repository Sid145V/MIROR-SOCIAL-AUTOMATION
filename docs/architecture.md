# Technical Architecture Overview

This document will describe the technical architecture of the MIROR Social Automation system.

## Planned System Overview
1. Read approved content from Google Sheets.
2. Read MIROR brand and visual rules.
3. Select an approved Instagram template.
4. Retrieve approved assets.
5. Generate only required visual assets.
6. Render exact Instagram creatives deterministically.
7. Run automated QA.
8. Prepare the final Instagram publishing package.
9. Publish through an automation platform.
